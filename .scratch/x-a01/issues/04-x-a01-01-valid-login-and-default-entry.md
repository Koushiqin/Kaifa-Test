# 04: X-A01-01 合法登录与默认入口

**What to build:** X-A01-01 的端到端用例：教师、助教、学生各用独立 context 登录，记录实际身份、默认落地页、可见导航项；消费 03 的管理员角色/入口预检结果，按判定树产出 `blocked` 或 `na`；低权限角色看到高权限入口时记 `failed`。产出用例结果片段和证据。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 三角色分别在独立 context 登录，记录 URL、默认落地页、导航项、身份/角色。

- [ ] 低权限角色看到高权限入口 → `failed`；“角色单列”按默认页非空壳、核心入口可见来判定。
- [ ] 助教导航差异只记录为观察项，不判失败。
- [ ] 产出用例结果片段（状态/note）和证据；不写最终 expected.json。
