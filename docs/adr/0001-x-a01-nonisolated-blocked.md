# X-A01 在隔离性待核实的测试环境执行，管理员与真实 TTL 按证据判定 blocked/na

- Status: accepted
- Date: 2026-11-26

X-A01 的被测站 `exam.1mpower.com` 由用户确认为非隔离共享环境，但与工作台任务卡“隔离测试环境”的表述冲突；预检时记录隔离性证据，结果按“隔离性待核实”记录。本轮没有管理员账号；会话真实 TTL 也可能无法在时间盒内验证。我们决定只执行可用三角色的断言：管理员账号缺失但站点存在管理员角色/入口时记 `blocked`；站点没有管理员角色/入口时记 `na` 并附证据；真实 TTL 无法验证时记 `blocked`；不把部分通过写成整体通过。结果先本地生成，未经明确授权不导入共享工作台。
